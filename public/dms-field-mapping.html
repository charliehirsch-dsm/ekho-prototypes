Design notes

Design notes
NEW INTERACTION
Formula builder
Each Ekho field opens a modal where dealers build formulas using multiple Lightspeed fields with + and − operators. Supports complex calculations like "MSRP − Rebate Amount".
NEW UI PATTERN
Inline formula preview
Each mapping row shows the formula expression as styled tags. Dealers can see at a glance whether a field uses a single source or a multi-field calculation.
NEW VALIDATION
Sample calculation
The modal shows a live calculation preview using sample Lightspeed data, so dealers can validate their formula produces the right result before saving.
Architecture
LAYOUT DECISION
Consistent left-to-right flow
All rows read left to right: Lightspeed formula on the left, arrow, Ekho destination on the right. Arrow reinforces the data flow direction.
UX PRINCIPLE
Progressive complexity
Simple 1:1 mappings look simple (just a field name). Multi-field formulas show the full expression. Dealers only see complexity when they need it.
Scope
V1 SCOPE LIMIT
Add/subtract only
V1 supports addition and subtraction operators only. Multiplication/division and conditional logic are out of scope.
PLACEHOLDER DATA
Lightspeed fields are placeholders
Using realistic placeholder field names. Will swap in actual Lightspeed API field names when available.
